## 1. Общее описание

Веб-приложение (PWA) — калькулятор для профессиональных маляров, специализирующихся на покраске МДФ фасадов, деревянных изделий и других поверхностей. Помогает точно рассчитывать количество всех компонентов лакокрасочного материала (основа, отвердитель, разбавитель, ускоритель, замедлитель) с учётом температуры окружающей среды.

## 2. Функциональные требования

### 2.1 Калькулятор расчёта

#### 2.1.0 Главное правило: всё считается от основы

Основной компонент принимается за **100%**. Каждая добавка — процент **от основы**,
а не от суммы смеси. Доля по умолчанию — **нижняя граница** диапазона из техпаспорта.

```
отвердитель = основа × ratio%
разбавитель = основа × ratio%
ускоритель  = основа × ratio%
```

Пример (PTS20700, 100 г основы):

| Компонент      | Доля | Расчёт        | Результат |
|----------------|------|---------------|-----------|
| PTS20700 основа| 100% | —             | 100 г     |
| PC20 отвердитель| 50% | 100 × 50%     | 50 г      |
| S50 разбавитель | 20% | 100 × 20%     | 20 г      |
| **Итого смеси** |      |               | **170 г** |

#### 2.1.1 Режим «По массе»
- Пользователь вводит количество **основного компонента** (г, кг или л)
- Все добавки считаются от него по формуле выше
- Вывод: компоненты с весом, видимой формулой расчёта и шкалой состава

#### 2.1.2 Режим «По площади»
- Пользователь вводит **площадь покрытия** (м²) и запас (0 / 10 / 15 / 20%)

**Что означает расход г/м² в каталоге ТехноКолор.** Цифра стоит в строке
**«Способ нанесения»** рядом с иконкой краскопульта — это расход того, что
проходит через пистолет, то есть **готовой рабочей смеси целиком**.
Подтверждения:

- Где каталог имеет в виду только основу, он пишет это явно —
  «Сухой остаток — **часть А**». В строке г/м² такой пометки нет.
- У PTS50 и PPS50 две строки «Способ нанесения» с разными иконками и
  своими г/м² — расход зависит от способа нанесения, а не от состава.
- Краситель CTU: разбавление 500–1000%, нанесение 80–100 г/м². Если бы
  цифра относилась к концентрату, на квадрат выливалось бы 400–1000 г
  жидкости — для морилки невозможно.

**Запас считается от итоговой суммы и выводится отдельной строкой.**
В основу он не закладывается: компоненты рассчитываются на чистую площадь,
поэтому их числа остаются «круглыми» и не зависят от выбранного запаса.

```
смесь на площадь = площадь × расход
основа = смесь ÷ (1 + доляОтвердителя% + доляРастворителя% + доляУскорителя%)
далее все компоненты = основа × доля%
запас = смесь × запас%
итого = смесь + запас
```

Пример (2 м², PTS20700, расход 150 г/м², запас 10%):

| Шаг              | Расчёт          | Результат |
|------------------|-----------------|-----------|
| Смесь на 2 м²    | 2 × 150         | 300 г     |
| Основа PTS20700  | 300 ÷ 1,70      | 176,5 г   |
| Отвердитель PC20 | 176,5 × 50%     | 88,2 г    |
| Разбавитель S50  | 176,5 × 20%     | 35,3 г    |
| *Сумма компонентов* |              | *300 г*   |
| Запас 10%        | 300 × 10%       | 30 г      |
| **Итого с запасом** |              | **330 г** |

Оба требования выполняются одновременно: каждый компонент равен
`основа × доля%`, и сумма компонентов совпадает с расходом.
Режимы взаимно обратимы: 176,5 г основы дают смесь ровно на 2 м².

**Материалы без разбавления.** У части материалов доля разбавителя
начинается с нуля (ATL500: 0–20%). При жаре к ним всё равно добавляется
замедлитель, поэтому в делителе учитывается фактический растворитель
(разбавитель + замедлитель), иначе сумма превысила бы расход.

#### 2.1.3 Режим «Свой» (произвольный)

Расчёт без привязки к материалу. Маляр задаёт сам:

- количество основы (г / кг / л);
- долю отвердителя, % от основы;
- долю разбавителя, % от основы;
- температуру.

Температурные правила применяются по схеме ПУ/акрила — для замедлителя
они совпадают. Полезно для материалов, которых нет в базе, и для проверки
пропорций «на глаз».

#### 2.1.4 Ускоритель и замедлитель: сверх или из разбавителя

По указанию производителя замедлитель добавляется **сверх** отвердителя
и разбавителя — 5–10% от основы при 25–30 °C и 10–15% при выше 30 °C.
Так и считается по умолчанию.

Каталог (стр. 19) относит S100 к разбавителям с очень низкой скоростью
испарения, но долю и способ ввода не задаёт. Косвенно схема «сверх»
подтверждается диапазонами: у PTS20700 разбавитель 20–30%, рабочие 20%
плюс 10% замедлителя дают ровно верхнюю границу.

Поскольку практика расходится, добавлена галочка **«Вычесть из
разбавителя»**: тогда замедлитель и ускоритель забираются из доли
разбавителя, и общий объём смеси не растёт. Галочка появляется только
когда есть что вычитать.

| PTS20700, 100 г основы, 33 °C | Сверх | С вычетом |
|---|---|---|
| Отвердитель PC20 | 50 г | 50 г |
| Разбавитель S50 | 20 г | 10 г |
| Замедлитель S100 | 10 г | 10 г |
| **Итого** | **180 г** | **170 г** |

Если весь растворитель выходит за паспортную верхнюю границу, расчёт
показывает предупреждение о переразбавлении.

### 2.2 Выбор материала (каскадные выпадающие списки)
1. **Производитель** — ТехноКолор и другие (добавляемые через админку)
2. **Материал** — фильтруется по производителю
3. **Отвердитель** — только совместимые с выбранным материалом
4. **Разбавитель** — только совместимые с выбранным материалом

### 2.3 Температурные корректировки
Система автоматически определяет зону температуры и добавляет рекомендации:

| Зона      | Диапазон   | Действие                                     |
|-----------|------------|----------------------------------------------|
| Холодно   | < 15°C     | Добавить ускоритель (рекомендация)           |
| Норма     | 15–25°C    | Стандартные пропорции                        |
| Тепло     | 25–30°C    | Добавить замедлитель S100 (рекомендация)     |
| Жарко     | > 30°C     | Замедлитель обязателен (влияет на расчёт)   |

Особые правила для **полиэфирных** материалов (PE):
- Всегда требуется ускоритель EA1 (2%)
- При температуре > 30°C доля EA1 снижается до 1%
- При холоде/норме — отвердитель EC1
- При тепле/жаре — отвердитель EC2

### 2.4 История расчётов
- Автоматическое сохранение каждого расчёта в localStorage
- Хранение: 30 дней, до 100 записей
- Данные хранятся только на устройстве пользователя (не передаются на сервер)
- Отображение: дата, материал, количество, температура
- Функции: просмотр деталей, повтор расчёта, удаление, очистка всей истории

### 2.5 Библиотека материалов
- Полный список всех материалов с техническими характеристиками
- Поиск по коду или названию
- Фильтры по типу: грунты, лаки, эмали, полиэфир, водные, красители
- Карточки с раскрываемыми деталями: пропорции, расход, описание, рекомендации

### 2.6 Администрирование
- Вход по паролю (SHA-256, пароль никогда не хранится открыто)
- Сессия 8 часов (sessionStorage)
- **CRUD для материалов**: добавление, редактирование, удаление
- **CRUD для производителей**: полное управление
- **Настройки сайта**: название, описание, контакты
- **Статистика**: количество материалов, записей в истории
- **Экспорт/импорт данных** в JSON

## 5. Нефункциональные требования

### 5.1 PWA (Progressive Web App)
- Работает полностью офлайн после первой загрузки
- Устанавливается на главный экран Android и iOS
- Service Worker с кешированием всех ресурсов (Cache-First)
- Манифест: `manifest.json` с иконками, темой, ориентацией

### 5.2 Интерфейс
- Мобильный дизайн (mobile-first)
- Нижняя навигация (3 вкладки)
- Тёмная тема через `prefers-color-scheme` + переключатель `data-theme`
- CSS переменные для цветовой схемы
- Адаптив для экранов от 320px

### 5.3 Данные и хранение
- Базовые данные: `js/data.js` (статический JS файл)
- Пользовательские данные: `localStorage` ключи `paintCalc_customData`, `paintCalc_history`
- Не требует сервера или базы данных
- Все данные хранятся только на устройстве

### 5.4 Безопасность
- Пароль администратора — только SHA-256 хеш в коде
- Нет серверной части — нет SQL-инъекций, нет утечек данных
- Авторизация через sessionStorage (не localStorage)

### 5.5 Доступность
- ARIA-атрибуты на интерактивных элементах
- Семантическая разметка (nav, section, header, main)
- `aria-live` для динамических обновлений
- Описательные `aria-label` для кнопок без текста

### 5.6 Язык
- Только русский язык (UI, уведомления, описания, документация)
