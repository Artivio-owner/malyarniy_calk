## 1. Общее описание

Веб-приложение (PWA) — калькулятор для профессиональных маляров, специализирующихся на покраске МДФ фасадов, деревянных изделий и других поверхностей. Помогает точно рассчитывать количество всех компонентов лакокрасочного материала (основа, отвердитель, разбавитель, ускоритель, замедлитель) с учётом температуры окружающей среды.

## 2. Функциональные требования

### 2.1 Калькулятор расчёта

#### 2.1.1 Режим «Количество»
- Пользователь вводит количество **основного компонента** (в г, кг или л)
- Система автоматически рассчитывает количество всех дополнительных компонентов по пропорциям из технического паспорта материала
- Вывод: таблица компонентов с весом, % и визуальная шкала состава

#### 2.1.2 Режим «Площадь»
- Пользователь вводит **площадь покрытия** (м²)
- Система использует данные **расхода материала** (г/м²) из технического паспорта
- Рассчитывается суммарное количество готовой смеси = площадь × расход × (1 + запас%)
- Предлагаются варианты запаса: без запаса, +10%, +15%, +20%
- Обратный расчёт: из суммарного количества вычисляется количество каждого компонента
- Формула: `основа = сумма ÷ (1 + долиОтвердителя + долиРазбавителя + долиУскорителя + долиЗамедлителя)`

### 2.2 Выбор материала (каскадные выпадающие списки)
1. **Производитель** — ТехноКолор и другие (добавляемые через админку)
2. **Материал** — фильтруется по производителю
3. **Отвердитель** — только совместимые с выбранным материалом
4. **Разбавитель** — только совместимые с выбранным материалом

### 2.3 Температурные корректировки
Система автоматически определяет зону температуры и добавляет рекомендации:

| Зона      | Диапазон   | Действие                                     |
|-----------|------------|----------------------------------------------|
| Холодно   | < 15°C     | Добавить ускоритель (рекомендация)           |
| Норма     | 15–25°C    | Стандартные пропорции                        |
| Тепло     | 25–30°C    | Добавить замедлитель S100 (рекомендация)     |
| Жарко     | > 30°C     | Замедлитель обязателен (влияет на расчёт)   |

Особые правила для **полиэфирных** материалов (PE):
- Всегда требуется ускоритель EA1 (2%)
- При температуре > 30°C доля EA1 снижается до 1%
- При холоде/норме — отвердитель EC1
- При тепле/жаре — отвердитель EC2

### 2.4 История расчётов
- Автоматическое сохранение каждого расчёта в localStorage
- Хранение: 30 дней, до 100 записей
- Данные хранятся только на устройстве пользователя (не передаются на сервер)
- Отображение: дата, материал, количество, температура
- Функции: просмотр деталей, повтор расчёта, удаление, очистка всей истории

### 2.5 Библиотека материалов
- Полный список всех материалов с техническими характеристиками
- Поиск по коду или названию
- Фильтры по типу: грунты, лаки, эмали, полиэфир, водные, красители
- Карточки с раскрываемыми деталями: пропорции, расход, описание, рекомендации

### 2.6 Администрирование
- Вход по паролю (SHA-256, пароль никогда не хранится открыто)
- Сессия 8 часов (sessionStorage)
- **CRUD для материалов**: добавление, редактирование, удаление
- **CRUD для производителей**: полное управление
- **Настройки сайта**: название, описание, контакты
- **Статистика**: количество материалов, записей в истории
- **Экспорт/импорт данных** в JSON

## 5. Нефункциональные требования

### 5.1 PWA (Progressive Web App)
- Работает полностью офлайн после первой загрузки
- Устанавливается на главный экран Android и iOS
- Service Worker с кешированием всех ресурсов (Cache-First)
- Манифест: `manifest.json` с иконками, темой, ориентацией

### 5.2 Интерфейс
- Мобильный дизайн (mobile-first)
- Нижняя навигация (3 вкладки)
- Тёмная тема через `prefers-color-scheme` + переключатель `data-theme`
- CSS переменные для цветовой схемы
- Адаптив для экранов от 320px

### 5.3 Данные и хранение
- Базовые данные: `js/data.js` (статический JS файл)
- Пользовательские данные: `localStorage` ключи `paintCalc_customData`, `paintCalc_history`
- Не требует сервера или базы данных
- Все данные хранятся только на устройстве

### 5.4 Безопасность
- Пароль администратора — только SHA-256 хеш в коде
- Нет серверной части — нет SQL-инъекций, нет утечек данных
- Авторизация через sessionStorage (не localStorage)

### 5.5 Доступность
- ARIA-атрибуты на интерактивных элементах
- Семантическая разметка (nav, section, header, main)
- `aria-live` для динамических обновлений
- Описательные `aria-label` для кнопок без текста

### 5.6 Язык
- Только русский язык (UI, уведомления, описания, документация)

## 7. Технологический стек
- **HTML5** — структура, семантика, ARIA
- **CSS3** — переменные, flex, grid, dark mode
- **Vanilla JavaScript (ES2020+)** — без фреймворков
- **PWA API** — Service Worker, Web App Manifest, Cache API
- **Web Crypto API** — `crypto.subtle.digest` для SHA-256
